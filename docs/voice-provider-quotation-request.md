# PGNT ASIAN TOPUP — VoIP provider quotation and test request

Subject: Wholesale VoIP termination quotation and test access — Afghanistan, Pakistan, Bangladesh and India

Hello,

We are evaluating wholesale outbound VoIP termination for an internet-calling feature in our mobile application, PGNT ASIAN TOPUP. Customers in our app will call ordinary public telephone numbers; recipients will not need to install our app. We are comparing providers before choosing a carrier.

Please provide a written, current EUR quotation for calls to the following mobile destinations and operators:

- Afghanistan: AWCC, Etisalat, MTN, Roshan
- Pakistan: Jazz, Telenor, Ufone, Zong
- Bangladesh: Grameenphone, Robi/Axiata, Banglalink
- India: Airtel, BSNL, Reliance Jio, Vodafone Idea

Please answer each item:

1. Exact current wholesale rate per minute for each listed operator and the date/time the rate becomes effective.
2. Available route classes (for example Bronze/Silver/Gold or Grey/Standard/Premium), and the rate for each class.
3. Billing increment, minimum billable duration, rounding method, and whether billing starts only after answer supervision.
4. Any connection fee, monthly fee, setup fee, minimum spend, minimum initial deposit/top-up, credit expiry, and refund rules.
5. Whether a few test calls can be made before any deposit; whether test credit is provided; and the destinations/operators allowed for tests.
6. SIP trunk details and supported authentication methods; whether IP allowlisting is available and whether a unique static IP is required.
7. Whether you offer a documented REST API or only SIP. If API is available, provide documentation for call initiation, call status events/webhooks, authentication/signature validation, and call termination.
8. Availability of real-time or downloadable Call Detail Records (CDRs), including unique call ID, destination, route/operator, answer time, end time, billable seconds, rate, and final charge.
9. Caller ID / CLI rules for calls originating from France/EU to the four destination countries. Which verified caller IDs are permitted? Is any caller ID rewriting or spoofing prohibited?
10. Coverage restrictions, excluded ranges, blocked destinations, expected answer-seizure ratio (ASR), average post-dial delay (PDD), quality/SLA, support hours, and escalation procedure.
11. Concurrent call/channel limits, throughput limits, anti-fraud controls, spend limits, and ability to disable a destination immediately.
12. KYC and onboarding requirements for a France-based business, including company registration/Kbis, VAT/SIREN details, and any telecom authorization or additional documentation required.
13. Please confirm whether this service may be resold to end customers inside our own mobile application, with our own retail tariff and per-customer wallet billing.
14. Please confirm data processing, call metadata retention, privacy/security terms, and whether calls are recorded by default (we do not want audio recording by default).

We would like to start with a small controlled test and will not commit to a large prepaid balance until route quality, CDR accuracy, commercial terms, caller-ID compliance and technical integration have been verified.

Please send your current rate deck and all relevant technical, legal and commercial documents.
